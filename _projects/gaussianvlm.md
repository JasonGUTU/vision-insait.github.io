**GaussianVLM** is the first **3D vision–language model** built on **language-aligned Gaussian splat** scenes: each primitive carries linguistic features for early modality alignment, without relying on object detectors.

A **dual sparsifier** compresses dense per-Gaussian features (~40k) into compact **task- and location-aware tokens** (~132) for an LLM decoder, enabling open-vocabulary, scene-centric reasoning on embodied benchmarks (SQA3D, 3D-LLM) and strong **out-of-domain** generalization on RGB-reconstructed scenes.
